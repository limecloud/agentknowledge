# Agent Knowledge v0.6.3

Agent Knowledge v0.6.3 修复并打磨本地化文档首页，让 `/en/` 与 `/zh/` 都成为面向读者和 AI 客户端的正式 landing page，而不是过长的概览正文。

## 重点

- 将本地化 index 页面修正为真正的 `layout: home` landing page。
- 为规范、快速开始、标准生态与 LLM 上下文提供更清晰的 hero actions。
- 首页保持简洁，把详细概念交给专门文档页承载。
- 核心 Agent Knowledge 规范继续兼容 v0.6.2。
