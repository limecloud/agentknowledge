# Agent Knowledge v0.6.0 Specification

The v0.6.0 specification snapshot is aligned with the current [latest specification](/en/specification).

## v0.6.0 changes

- Agent Knowledge is explicitly positioned as an interoperable companion standard to Agent Skills.
- Adds `document-first`, `wiki-first`, and `hybrid` profiles.
- Adds `documents/` as a primary fact-source path.
- Adds `runtime.mode: data | persona`.
- Adds recommended Builder Skill provenance.
- Expands operations knowledge pack types.

See the [latest specification](/en/specification) for the full field, directory, and runtime rules.
