# Agent Knowledge v0.7.0 Specification

The v0.7.0 specification snapshot is aligned with the current [latest specification](/en/specification).

## v0.7.0 changes

- Adds optional ontology-aware knowledge packs.
- Adds `ontology/` as a structured data directory for concepts, relations, claims, evidence, constraints, and coverage matrices.
- Adds `metadata.primaryOntology`.
- Adds `content-ontology` as a standard `type`.
- Defines resolver behavior for selected ontology subgraphs.
- Clarifies that ontology files are data, not executable Skills, scripts, workflows, prompts, or instructions.

See [Ontology-aware packs](/en/authoring/ontology-packs) for the authoring guide.
